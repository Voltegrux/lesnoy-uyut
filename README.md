# Лесной Уют — Лендинг аренды загородных домов

Современный одностраничный лендинг для компании по аренде загородных домов в Подмосковье.

## Технологии

- **Next.js 15** — App Router, Server/Client Components
- **React 19** + **TypeScript**
- **Tailwind CSS 3** — кастомная тема с природными цветами
- **Framer Motion** — анимации и параллакс
- **React Leaflet** — интерактивная карта без API-ключа

## Запуск проекта

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Структура

```
src/
├── app/
│   ├── layout.tsx       # SEO, шрифты, мета-теги
│   ├── page.tsx         # Главная страница
│   └── globals.css      # Глобальные стили, grain-текстура
├── components/
│   ├── Preloader.tsx    # Анимированный прелоадер
│   ├── Header.tsx       # Фиксированная шапка с мобильным меню
│   ├── Hero.tsx         # Hero с параллаксом
│   ├── Houses.tsx       # Каталог домов (6 карточек)
│   ├── About.tsx        # О компании + фотоколлаж
│   ├── Testimonials.tsx # Слайдер отзывов с автопрокруткой
│   ├── Map.tsx          # Раздел карты
│   ├── MapClient.tsx    # Leaflet-карта (client only)
│   ├── Contacts.tsx     # Контакты + форма обратной связи
│   ├── Footer.tsx       # Подвал
│   └── ScrollToTop.tsx  # Кнопка «наверх»
├── hooks/
│   └── useReveal.ts     # Intersection Observer для reveal
└── lib/
    └── data.ts          # Данные домов и отзывов
```

## Дизайн

Цветовая палитра (природная/премиальная):

| Переменная | Цвет |
|---|---|
| `--forest` | `#1C3829` (тёмно-зелёный) |
| `--cream` | `#F7F3EE` (сливочный) |
| `--sand` | `#D4C4A8` (песочный) |
| `--earth` | `#8B6F4E` (кора дерева) |

Шрифты:
- **Cormorant Garamond** — заголовки (элегантный, редакционный)
- **Jost** — основной текст (чистый, геометрический)

## Что включено

- Preloader с SVG-анимацией
- Hero-секция с параллаксом и пословным появлением заголовка
- 6 карточек домов с hover-zoom и тенями
- Блок «О нас» с асимметричным коллажем и счётчиками
- Слайдер отзывов с автопрокруткой (6 отзывов)
- Интерактивная карта Leaflet с кастомными маркерами
- Форма обратной связи с валидацией и success-состоянием
- Фиксированная шапка с адаптивным мобильным меню
- Кнопка «Наверх»
- Grain-текстура overlay
- Плавный скролл и scroll-reveal анимации
- SEO: title, description, OG-теги, favicon
- Полная адаптивность (mobile / tablet / desktop)
